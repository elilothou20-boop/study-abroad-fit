# 留学梦校申请评估 Skill · study-abroad-fit

> 与 AI 鏖战 20 小时，把个人 DIY 留学申请的研判思路整理成一套可复用的选校与背景评估流程。

面向本科在读或已毕业、计划申请**英国、美国、澳大利亚、加拿大、香港、新加坡硕士**的同学。把自己的背景和目标项目交给具备相应能力的 AI，逐项目核验要求、梳理优势与缺口，并生成申请规划报告。

本仓库分享的是 **AI 评估规则与空白填写模板**。它不是可执行程序，也不是自动抓取招生数据的网站；联网检索、推理和文件生成由你使用的 AI 工具完成。

并且不同的AI所产出的评价会有不同，某些AI评价会比较严格，导致分数较低；不同AI能力的差异，得到的报告质量会不一致；可以尝试多个ai交叉互检；


## 能做什么

- **整理背景与目标**：本科院校、专业、GPA／均分、语言、实习、竞赛、科研、作品集、文书、推荐信，以及入学时间和递交计划。
- **核验项目官方要求**：针对具体入学年份查询学历和先修课程、语言要求、申请截止、推荐信数量、GRE／GMAT 倾向、作品集与补件规定，并保留来源。
- **十个维度分析匹配**：本科教育背景、GPA／课程／排名、语言、实习工作、项目竞赛、作品集、文书动机、推荐信、专项考试、科研论文。
- **研判竞争与证据局限**：有可比官方数据和往届资料时用于参考；缺少同口径资料时标注暂估，不把个别录取案例当作个人录取概率。
- **形成申请级别与行动建议**：统一启动口径后可用“稳妥／乐观／主申／冲刺／难度较大”表达规划判断；根据资格、材料、时间与证据综合判断。
- **生成报告**：PDF 每个目标项目一页，包含分项准备度、简短依据、主要风险与下一步；需要时可增加 Word 详细版。网页版本须另行要求，当前规则未提供固定网页模板。

打开本仓库右上方的 **Code → Download ZIP**，解压后即可使用。也可以单独下载以下文件：

| [SKILL.md](SKILL.md) | 作者提供的完整合并版规则，包含全部内嵌参考章节和报告模板 |

`SKILL.md` 中的 `===== FILE: ... =====` 标记表示同一文件里的内嵌章节。这里是**合并版文本**，文中的相对路径用于定位章节，不代表仓库缺少外部文件。推荐整份上传给 AI；不要把它直接当作已完成适配的、可一键安装到所有平台的 Skill 包。

## 使用方法

1. 下载并解压仓库。
2. 复制 `User-Input-Template.txt` 到自己的私人文件夹，填写个人背景和目标项目。先填申请目标、本科背景、语言与考试信息即可开始，其他内容可后补。
3. 将**完整 `SKILL.md` + 填写后的模板**一同发送给 AI。已有简历或成绩单也可作为补充，先遮去不需要的个人身份信息。
4. 发送下方启动提示。AI 应先整理信息、追问必要缺口，再核验和评估项目。
5. 检查项目全称、入学年份、语言原件、官方期限和材料状态；需要修正时提供新信息，让 AI 更新受影响项目。

### 可直接复制的启动提示

```text

请根据我上传的 SKILL.md 完整规则和填写模板，给我生成报告。

```

### AI 工具需要具备什么能力

- **读取完整文件**：必须能读到规则的所有章节，不能只根据文件名或摘要评估。
- **联网检索**：用于核验当年官方项目要求。不能联网时，可提供官方材料，但需要保留未核验说明。
- **生成实际文件**：需要输出 PDF／Word 时，平台必须支持对应文件生成或代码执行；单纯文字对话不能保证产生可下载附件。

Codex、Claude Code、豆包工作版、WorkBuddy、千问工作版 等工具可按其实际功能尝试使用；**不承诺所有平台、所有模型或所有版本都兼容**。这份仓库没有完成跨平台统一兼容性测试。

## 使用声明

1. 本框架基于个人 DIY 申请经验整理，用于工具分享、学习与交流，不属于中介服务产品。
2. 评分是经验性规划参考，不能等同于招生委员会判断、录取概率、资格认证或录取承诺。
3. 院校政策可能随年份和批次变化；所有要求以对应项目的官方最新公告、申请系统和正式通知为准。
4. AI 可能出现检索错误、遗漏、推理偏差或文件生成失败。重要申请信息应自行复核；不能用暂估分掩盖必需材料缺失。
5. 未阅作品、未阅文书和用户自评必须保留暂估标记；计划中的考试与经历不能当作已完成成果。
6. 仅供学习、交流和娱乐参考，不构成专业申请指导。使用者应自行判断建议是否适合自己的情况。
7. 不要在公开 Issues、Pull Requests 或仓库中上传已填写的背景、成绩单、身份证件、保密推荐信或账号密钥。提交问题时请先去除私人信息。
